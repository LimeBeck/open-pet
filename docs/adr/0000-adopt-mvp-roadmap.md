# ADR-000: MVP-спецификация как источник истины

- Статус: Accepted
- Дата: 2026-08-06
- Этап: —
- Связано: [`desktop-ai-pet-mvp-spec-roadmap.md`](../desktop-ai-pet-mvp-spec-roadmap.md)

## Контекст

Репозиторий `open-pet` инициализирован под продукт Desktop AI Pet. Продуктовые
границы, privacy-модель, стек и этапность уже проработаны в отдельном документе.
Нужно зафиксировать, чем разработка руководствуется при расхождениях, чтобы scope
не расползался по частным решениям в коде и обсуждениях.

## Рассматриваемые варианты

### Вариант A — спецификация как источник истины, отклонения через ADR

Один документ задаёт рамку; всё, что от него отходит, оформляется отдельным
решением. Цена: любое изменение курса требует письменной работы.

### Вариант B — спецификация как справочный материал

Документ описывает намерение, решения принимаются по ходу. Дешевле в моменте,
но границы MVP из §4.3 перестают что-либо гарантировать, а privacy-модель
превращается в набор пожеланий.

## Критерии выбора

- Границы MVP должны быть проверяемы: по документу видно, входит фича или нет.
- Privacy-ограничения должны быть неотменяемы в частном порядке.
- Смена курса должна оставлять след с причиной.

## Решение

Принят вариант A. Разработка ведётся по
[`desktop-ai-pet-mvp-spec-roadmap.md`](../desktop-ai-pet-mvp-spec-roadmap.md)
(актуальная версия — Draft v0.2 от 7 августа 2026; история версий — в §18
документа).

Документ задаёт:

- продуктовые границы (§4) и privacy-модель (§4.2, §9);
- эталонную платформу KDE Plasma 6.2+ / Wayland и стек Qt 6 + QML, Rust core (§2);
- архитектуру host/core/adapters (§8);
- функциональные и нефункциональные требования (§6, §7);
- этапы M0–M7 (§12) и Definition of Done (§13).

## Последствия

- Scope вне §4.1 не берётся в работу без явного запроса и нового ADR.
- Текущий ориентир — M0. Technical spikes; следом ADR-001…004 из §16.
- Существенные изменения самого документа фиксируются повышением его версии
  и строкой в §18; ссылка на актуальную версию остаётся в этом ADR.
  Первая такая правка — [ADR-006](0006-memory-metric.md), §7 в v0.2.
- Правила повседневной работы, вытекающие отсюда, живут в [AGENTS.md](../../AGENTS.md).
