# Эталонная система

Все нефункциональные цели §7 спецификации (старт до 3 секунд, RSS до 150 МБ,
до 2% ядра в idle, 60 FPS) измеряются на одной зафиксированной конфигурации.
Без неё числа не значат ничего: «2% ядра» на разном железе — разные вещи.

Конфигурация фиксируется по итогам M0 (§16 спецификации). До этого поля пустые
намеренно — заполнять их догадками хуже, чем оставить пустыми.

## Матрица совместимости

Заполняется по мере проверки. Спецификация обещает Plasma 6.2+ и Qt 6;
точная матрица дистрибутивов фиксируется после spike (§7).

|---|---|---|---|---|

Статусы: `эталон`, `проверено`, `известны проблемы`, `не проверялось`.

## Методика замеров

Фиксируется вместе с первыми числами, чтобы замеры были воспроизводимы:

- как измеряется время до появления питомца (§7, «не позднее 3 секунд»);
- как измеряется RSS и в какой момент после старта;
- как измеряется CPU в idle и на какой длительности окна;
- как проверяется отсутствие сетевых запросов при выключенной LLM;
- условия 8-часового soak-теста из §13.
