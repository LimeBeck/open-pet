# Privacy-модель

Развёрнутое изложение §4.2 и §9 спецификации. Источник истины — сама
[спецификация](desktop-ai-pet-mvp-spec-roadmap.md); при расхождении прав тот
документ, а этот правится следом.

Модель — не настройка приватности, а ограничение архитектуры. Приложение не читает
запрещённые данные не потому, что переключатель выключен, а потому, что не имеет
кода, который умеет их читать. Проверка на ревью формулируется так: если появился
источник данных, которого нет в таблице ниже, изменение неверно независимо
от того, что с этими данными делается дальше.

## Что приложение наблюдает

| Источник | Что получает | Чего не получает |
|---|---|---|
| Клавиатура и мышь | Время последней активности, переход idle ↔ active | Клавиши, координаты, текст, частоту нажатий и кликов |
| Активное приложение | Нормализованный app id и факт смены | Содержимое окна, заголовок документа |
| Уведомление | Факт события, опционально категория | Текст, отправителя, вложения |
| Питание | Флаг питания от сети, процент заряда, состояние | — |
| Сессия | Сон, возобновление, блокировка | — |
| Медиа | `playing` / `paused` / `stopped` | Аудиопоток, микрофон, распознавание звука |
| Экран | Ничего | Скриншоты, OCR, видеопоток |
| Буфер обмена | Ничего | Содержимое, факт изменения |

Отдельно: приложение не наблюдает файловую систему пользователя, историю браузера,
сетевую активность и список запущенных процессов.

Если безопасный источник события недоступен, capability помечается `unsupported`,
и приложение продолжает работать без неё. Недоступность источника никогда
не служит поводом взять данные другим, менее аккуратным путём —
см. [ADR-004](adr/0004-notification-observation.md), где такой путь отклонён явно.

## Управление источниками

У каждого класса событий отдельный переключатель (§9). Выключенный источник
не подписывается на события вообще, а не фильтрует их после получения.

Команда «пауза» останавливает реакции, сохраняя tray-меню (§FR-2).
«Сбросить локальные данные» удаляет настройки и историю; вручную импортированные
Pet Pack не удаляются без отдельного подтверждения (§9).

## Что хранится локально

| Данные | Назначение |
|---|---|
| Настройки UI и разрешённых capabilities | Восстановление состояния между запусками |
| Выбранный Pet Pack и его проверенный hash | Обнаружение подмены и повреждения |
| Параметры LLM без секретов | Конфигурация провайдера |
| Короткая история идентификаторов показанных фраз | Защита от повторов (§FR-6) |
| Обезличенная диагностика уровня warning/error | Разбор проблем |

Хранится **идентификатор** показанной фразы, не её текст и не событие, которое
её вызвало.

## Что не хранится никогда

- клавиши, текст ввода, координаты мыши;
- заголовки документов и содержимое окон;
- текст и отправители уведомлений;
- аудио, скриншоты, буфер обмена;
- полная временная история активных приложений — по ней восстанавливается
  распорядок дня пользователя, поэтому хранится только текущее значение.

Сырые события не сохраняются. Диагностический журнал кольцевой и обезличенный (§7).

## Секреты

API-ключи и учётные данные провайдеров хранятся только в Secret Service / KWallet.
Они не попадают в конфигурационные файлы, репозиторий, фикстуры и диагностику;
в логах и отчётах об ошибках редактируются всегда (§FR-7).

## Сеть

Пока пользователь явно не включил LLM-провайдера, приложение не делает сетевых
запросов — ноль, включая проверки обновлений и телеметрию (§7). Все основные
реакции и локальные реплики доступны без сети (§13, п. 5).

## Что уходит в LLM

Только минимальный семантический контекст — эмоция и локаль, например:

```json
{ "emotion": "charging", "locale": "ru" }
```

Не уходит: исходное D-Bus-событие, app id, категория уведомления, время активности,
идентификаторы устройства и пользователя, история предыдущих реплик.

Перед первым включением сетевого провайдера UI показывает точный пример payload,
который будет отправлен (§9). Ошибка, тайм-аут, rate limit или offline прозрачно
переключают ответ на локальный шаблон (§FR-6) — отсутствие ответа от модели
никогда не приводит к повторной отправке расширенного контекста.

Приложение не обращается к LLM самостоятельно вне обработки события —
незапрошенные обращения исключены из MVP (§4.3).

## Pet Pack

Импортируемый пакет — данные, не код (§FR-8): JSON, PNG и анимированный WebP.
Ни скриптов, ни бинарных плагинов, ни активного содержимого в SVG/HTML, ни внешних
URL. Архив распаковывается с защитой от path traversal и decompression bomb.
Пакет не получает доступа к событиям, настройкам и сети.

## Как это проверяется

- Unit-тесты на redaction секретов и на содержимое диагностического журнала (§11).
- Contract-тесты адаптеров: каждый адаптер отдаёт только поля своего DTO из §FR-4.
- Security-тесты Pet Pack: path traversal, decompression limits, malformed media (§11).
- Проверка отсутствия сетевых запросов при выключенной LLM — часть Definition
  of Done (§13, п. 4 и 5).
